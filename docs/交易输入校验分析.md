## 🔧 需要改进的地方

### 1. 价格输入改进

**问题**：
- 可以输入任意小数位数
- 没有实时显示价格范围提示
- 没有显示当前市价参考

**建议**：
```tsx
<input
  type="number"
  value={displayPrice}
  onChange={(e) => {
    let value = parseFloat(e.target.value);
    if (Number.isNaN(value) || value <= 0) return;

    // 限制3位小数
    value = Math.round(value * 1000) / 1000;

    // 检查价格范围
    const currentPrice = parseNumericValue(currentProduct?.price ?? "0");
    const tickSize = 0.1; // 根据价格动态计算
    const minPrice = currentPrice - tickSize * 20;
    const maxPrice = currentPrice + tickSize * 20;

    if (value >= minPrice && value <= maxPrice) {
      setPrice(value);
    }
  }}
  onBlur={() => {
    // 失焦时校验并调整
    let adjustedPrice = price;
    adjustedPrice = Math.round(adjustedPrice * 1000) / 1000;
    setPrice(adjustedPrice);
  }}
  step="0.001"
  min={minPrice}
  max={maxPrice}
/>
```

### 2. 股数输入改进

**问题**：
- 可以输入非手数倍数的数字
- 没有显示最大可买/可卖数量
- 没有自动调整到最近的手数倍数

**建议**：
```tsx
<input
  type="number"
  value={displayQuantity}
  onChange={(e) => {
    let value = parseInt(e.target.value, 10);
    if (Number.isNaN(value) || value <= 0) return;

    // 自动调整到手数倍数
    const remainder = value % lotSize;
    if (remainder !== 0) {
      // 向下调整到手数倍数
      value = Math.floor(value / lotSize) * lotSize;
    }

    setQuantity(value);
  }}
  onBlur={() => {
    // 失焦时确保是手数倍数
    const adjusted = Math.round(quantity / lotSize) * lotSize;
    setQuantity(Math.max(lotSize, adjusted));
  }}
  step={lotSize}
  min={lotSize}
  max={maxQuantity}
/>
<p className="text-label text-[#bc9871]">
  {copy.perLot(lotSize)} | 最大可{side === "buy" ? "买" : "卖"}: {maxQuantity}股
</p>
```
