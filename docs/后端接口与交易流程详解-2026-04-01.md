## 2. 核心交易流程详解

### 2.1 完整交易流程图

```
┌─────────────┐
│  用户下单   │
└──────┬──────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第一阶段：规则校验 (OrderService.placeOrderV1)          │
│  ✓ 标的白名单校验                                        │
│  ✓ 交易时段校验                                          │
│  ✓ 单日买入次数 ≤ 20                                     │
│  ✓ 限价单轮候数量 ≤ 5                                    │
│  ✓ 价格范围校验 (按盘价 ±20 ticks)                       │
│  ✓ 底价限制 (买入 ≥ 0.05, 卖出 ≥ 0.01)                  │
│  ✓ 数量手数校验 (必须整手)                               │
│  ✓ 可用资金/持仓校验                                     │
└──────┬───────────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第二阶段：资源冻结 (AccountLedgerService)               │
│  限价单冻结逻辑：                                         │
│  • 买入：冻结 可用资金 = 价格 × 数量 + 预估手续费        │
│  • 卖出：冻结 可用持仓数量                                │
│  市价单不冻结，直接撮合                                   │
└──────┬───────────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第三阶段：订单撮合 (MatchingService.matchOrders)        │
│  撮合条件判断：                                           │
│  • 市价单：立即以当前按盘价成交                           │
│  • 限价买入：买入价 ≥ 按盘价 → 成交                      │
│  • 限价卖出：卖出价 ≤ 按盘价 → 成交                      │
│  撮合价格：统一使用当前按盘价                             │
└──────┬───────────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第四阶段：费用计算 (FeeCalculator)                      │
│  5项费用计算：                                            │
│  1. 模拟经纪佣金：成交金额 × 0.25%，最低 HK$100          │
│  2. 模拟交易处理费：每手 HK$2.5，范围 HK$30-200 (仅买入) │
│  3. 模拟印花税：成交金额 × 0.1%，最低 HK$1               │
│  4. 模拟交易征费：成交金额 × 0.003%                      │
│  5. 模拟交易费：成交金额 × 0.005%                        │
└──────┬───────────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第五阶段：账本更新 (AccountLedgerService.onOrderMatched)│
│  买入：                                                   │
│  • 可用资金 − (成交金额 + 手续费)                         │
│  • 在途持仓 + 成交数量                                    │
│  卖出：                                                   │
│  • 可用持仓 − 成交数量                                    │
│  • 可用资金 + (成交金额 − 手续费)                         │
└──────┬───────────────────────────────────────────────────┘
       ↓
┌──────────────────────────────────────────────────────────┐
│  第六阶段：T+2 结算 (SettlementScheduler)                │
│  每日 06:05 (HKT) 自动执行：                              │
│  • 在途持仓 → 可用持仓                                    │
│  • 在途资金 → 可用资金                                    │
│  • 更新结算状态为 "已交收"                                │
└──────────────────────────────────────────────────────────┘
```

### 2.2 订单生命周期

```
创建订单 (PENDING)
     ↓
撮合成功 (FILLED / PARTIAL_FILLED)
     ↓
等待结算 (SETTLING)
     ↓
T+2交收 (SETTLED)

异常分支：
• 用户撤单 → CANCELED
• 收市未成交 → CANCELED (自动)
• 规则拦截 → REJECTED
```

### 3.1 交易相关接口

#### 3.1.1 提交订单

**接口**: `POST /api/v1/trade/orders`

**请求头**:
```
X-User-Id: {用户ID}
X-Idempotency-Key: {幂等键} (可选，24小时语义幂等)
X-Lang: zh-Hant | zh-Hans | en (可选)
```

**请求体**:
```json
{
  "stockCode": "00700.HK",
  "side": "BUY",
  "orderType": "LIMIT",
  "price": 300.20,
  "quantity": 100
}
```

**字段说明**:
- `stockCode`: 股票代码，格式为 `{代码}.HK`
- `side`: 买卖方向，`BUY` 或 `SELL`
- `orderType`: 订单类型，`LIMIT` (限价) 或 `MARKET` (市价)
- `price`: 委托价格 (限价单必填，市价单不填)
- `quantity`: 委托数量，必须为该股票每手股数的整数倍

**响应体**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "orderId": "ord_20260401_abc123",
    "stockCode": "00700.HK",
    "stockName": "騰訊控股",
    "side": "BUY",
    "orderType": "LIMIT",
    "price": 300.20,
    "quantity": 100,
    "status": "PENDING",
    "validityType": "DAY_CLOSE",
    "validityNote": "限價單有效至今日收市（16:00 HKT）。",
    "estimatedFee": 85.50,
    "estimatedTotal": 30105.50,
    "tradableNow": true,
    "language": "zh-Hant"
  }
}
```

**业务规则**:
1. **白名单校验**: 仅允许交易指定股票池
2. **交易时段**: 仅交易日 09:30-12:00, 13:00-16:00 可下单
3. **买入次数**: 单日最多 20 笔买入
4. **限价轮候**: 最多 5 个排队中限价单
5. **价格限制**:
   - 限价必须在按盘价 ±20 个价位内
   - 买入价 ≥ HK$0.05
   - 卖出价 ≥ HK$0.01
6. **数量限制**: 必须为整手数，不允许碎股
7. **资金校验**: 可用资金 ≥ 委托金额 + 预估手续费

**幂等性保证**:
- 通过 `X-Idempotency-Key` 实现幂等
- 同一 key + 同一请求 → 返回同一 orderId
- 同一 key + 不同请求 → 返回 400 错误
- 幂等窗口期: 24 小时

## 4. 撮合机制详解

### 4.1 撮合触发时机

撮合引擎在以下情况触发：

1. **行情推送**: RabbitMQ 接收到 `quote.queue.hk.realTime` 行情更新
2. **手动触发**: 通过 `/api/v1/trade/quote/debug-push` 接口注入测试行情
3. **定时任务**: (可选) 定期检查未撮合订单

### 4.2 撮合价格确定

```
撮合价格 = 当前按盘价 (Nominal Price)
```

**按盘价来源**:
1. 优先使用行情中的 `nominalPrice` 字段
2. 次选使用卖一价 (对于买单) 或买一价 (对于卖单)
3. 最后使用昨收价

### 4.3 撮合条件判断

#### 4.3.1 市价单

```
立即成交条件：
• 交易时段内
• 有可用流动性

成交价格 = 当前按盘价
```

#### 4.3.2 限价单

```
买入限价单成交条件：
委托买入价 ≥ 当前按盘价

卖出限价单成交条件：
委托卖出价 ≤ 当前按盘价

成交价格 = 当前按盘价 (不是委托价)
```

### 4.4 订单簿撮合逻辑

当行情包含买卖盘深度时，采用逐级消耗撮合：

```java
// 伪代码示例
for (Level askLevel : asks) {  // 卖盘
    for (Order buyOrder : buyQueue) {
        if (buyOrder.price >= askLevel.price) {
            matchQuantity = min(buyOrder.remaining, askLevel.volume);
            executeMatch(buyOrder, askLevel.price, matchQuantity);
        }
    }
}

for (Level bidLevel : bids) {  // 买盘
    for (Order sellOrder : sellQueue) {
        if (sellOrder.price <= bidLevel.price) {
            matchQuantity = min(sellOrder.remaining, bidLevel.volume);
            executeMatch(sellOrder, bidLevel.price, matchQuantity);
        }
    }
}
```

### 4.5 部分成交处理

```
订单数量: 1000股
成交量: 300股
剩余: 700股

状态变更: PENDING → PARTIAL_FILLED
已成交数量: 300股
剩余数量: 700股 (继续排队)
```

## 5. T+2 结算机制详解

### 5.1 T+2 计算逻辑

**交易日历服务** (`TradingCalendarService`):

```java
public LocalDate calculateSettlementDate(LocalDate tradeDate) {
    // T+2 营业日
    return tradingCalendarService.addTradingDays(tradeDate, 2);
}

public LocalDate addTradingDays(LocalDate fromDate, int days) {
    LocalDate cursor = fromDate;
    int added = 0;
    while (added < days) {
        cursor = cursor.plusDays(1);
        if (isTradingDay(cursor)) {  // 跳过周末和节假日
            added++;
        }
    }
    return cursor;
}
```

**示例**:
```
交易日: 2026-04-01 (周三)
T+1: 2026-04-02 (周四)
T+2: 2026-04-03 (周五) ← 结算日

如果遇到周末:
交易日: 2026-04-03 (周五)
T+1: 2026-04-06 (周一)
T+2: 2026-04-07 (周二) ← 结算日
```

### 5.3 结算流程

```java
public void processSettlements(LocalDate settlementDate) {
    // 1. 查询当日应结算的订单
    List<OrderSettlementEntity> settlements =
        orderSettlementMapper.findBySettlementDate(settlementDate);

    // 2. 遍历处理每个结算记录
    for (OrderSettlementEntity settlement : settlements) {
        if (settlement.getStatus() == SETTLING) {
            // 买入：在途持仓 → 可用持仓
            if (settlement.getSide() == BUY) {
                position.transitQuantity -= settlement.getQuantity();
                position.tradableQuantity += settlement.getQuantity();
            }

            // 卖出：在途资金 → 可用资金
            if (settlement.getSide() == SELL) {
                account.transitCash -= settlement.getNetAmount();
                account.availableCash += settlement.getNetAmount();
            }

            // 3. 更新结算状态
            settlement.setStatus(SETTLED);
            orderSettlementMapper.updateById(settlement);
        }
    }
}
```

## 6. 费用计算详解

### 6.1 五项费用计算公式

**费用计算器** (`FeeCalculator`):

```java
public BigDecimal calculateTotalFee(
    BigDecimal transactionAmount,  // 成交金额
    boolean isBuy,                 // 是否买入
    int lots                       // 手数
) {
    // 1. 模拟经纪佣金
    BigDecimal commission = transactionAmount × 0.0025;
    commission = max(commission, 100.00);  // 最低 HK$100

    // 2. 模拟交易处理费 (仅买入)
    BigDecimal processingFee = 0;
    if (isBuy) {
        processingFee = 2.5 × lots;
        processingFee = clamp(processingFee, 30.00, 200.00);
    }

    // 3. 模拟印花税
    BigDecimal stampDuty = transactionAmount × 0.001;
    stampDuty = max(stampDuty, 1.00);  // 最低 HK$1

    // 4. 模拟交易征费
    BigDecimal tradingLevy = transactionAmount × 0.00003;

    // 5. 模拟交易费
    BigDecimal tradingFee = transactionAmount × 0.00005;

    return commission + processingFee + stampDuty + tradingLevy + tradingFee;
}
```

### 6.2 费用计算示例

**示例1: 买入腾讯 1000股，成交价 300.00**

```
成交金额 = 300.00 × 1000 = HK$ 300,000
手数 = 1000 ÷ 100 = 10手

1. 经纪佣金 = 300,000 × 0.25% = 750.00
2. 交易处理费 = 2.5 × 10 = 25.00 → 最低30.00
3. 印花税 = 300,000 × 0.1% = 300.00
4. 交易征费 = 300,000 × 0.003% = 9.00
5. 交易费 = 300,000 × 0.005% = 15.00

总费用 = 750 + 30 + 300 + 9 + 15 = HK$ 1,104.00
实际支付 = 300,000 + 1,104 = HK$ 301,104.00
```

**示例2: 卖出腾讯 1000股，成交价 300.00**

```
成交金额 = 300.00 × 1000 = HK$ 300,000
手数 = 1000 ÷ 100 = 10手

4. 交易征费 = 300,000 × 0.003% = 9.00
5. 交易费 = 300,000 × 0.005% = 15.00
```

## 7. 账本服务详解

### 7.1 账户状态模型

**账户状态** (`AccountState`):

```java

    BigDecimal availableCash;   // 可用资金
    BigDecimal frozenCash;      // 冻结资金
    BigDecimal transitCash;     // 在途资金 (T+2)

```

**持仓状态** (`PositionState`):

```java

    String stockCode;
    int tradableQuantity;       // 可用数量
    int frozenQuantity;         // 冻结数量
    int transitQuantity;        // 在途数量 (T+2)
    BigDecimal totalCost;       // 总成本
}
```

### 7.2 资源冻结逻辑

**买入限价单**:

```java
// 1. 计算冻结金额
reserveAmount = price × quantity + estimatedFee;

// 2. 校验可用资金
if (account.availableCash < reserveAmount) {
    throw new IllegalArgumentException("Insufficient cash balance");
}

// 3. 冻结资金
account.availableCash -= reserveAmount;
account.frozenCash += reserveAmount;

// 4. 记录冻结信息
reservation = OrderReservation.buy(userId, stockCode, quantity, reserveAmount);
```

**卖出限价单**:

```java
// 1. 校验可用持仓
if (position.tradableQuantity < quantity) {
    throw new IllegalArgumentException("Insufficient holdings");
}

// 2. 冻结持仓
position.tradableQuantity -= quantity;
position.frozenQuantity += quantity;

// 3. 记录冻结信息
reservation = OrderReservation.sell(userId, stockCode, quantity);
```

### 7.3 成交后账本更新

**买入成交**:

```java
// 1. 计算实际成本
actualCost = matchedAmount + fee;

// 2. 从冻结资金中扣除
account.frozenCash -= reservedAmount;

// 3. 退还差额或补扣不足
refund = reservedAmount - actualCost;
if (refund >= 0) {
    account.availableCash += refund;  // 退还多余
} else {
    account.availableCash -= refund.abs();  // 补扣不足
}

// 4. 增加在途持仓
position.transitQuantity += matchedQuantity;
position.totalCost += actualCost;

// 5. 注册结算记录
registerSettlementEntry(order, settlementDate);
```

**卖出成交**:

```java
// 1. 解冻持仓
position.frozenQuantity -= matchedQuantity;

// 2. 计算实际收入
netAmount = matchedAmount - fee;

// 3. 增加在途资金
account.transitCash += netAmount;

// 4. 更新成本
averageCost = position.totalCost / position.totalQuantity;
position.totalCost -= averageCost × matchedQuantity;

// 5. 注册结算记录
registerSettlementEntry(order, settlementDate);
```

```java
public boolean isTradingSession(ZonedDateTime time) {
    LocalTime localTime = time.toLocalTime();
    DayOfWeek dayOfWeek = time.getDayOfWeek();

    // 周末不可交易
    if (dayOfWeek == SATURDAY || dayOfWeek == SUNDAY) {
        return false;
    }

    // 非交易日 (节假日) 不可交易
    if (!tradingCalendarService.isTradingDay(time.toLocalDate())) {
        return false;
    }

    // 上午时段: 09:30-12:00
    boolean morningSession = !localTime.isBefore(MORNING_OPEN)
                          && !localTime.isAfter(MORNING_CLOSE);

    // 下午时段: 13:00-16:00
    boolean afternoonSession = !localTime.isBefore(AFTERNOON_OPEN)
                            && !localTime.isAfter(MARKET_CLOSE);

    return morningSession || afternoonSession;
}
```

```java
public String determineValidityType(String orderType, boolean tradableNow) {
    if ("MARKET".equalsIgnoreCase(orderType)) {
        return "IMMEDIATE";
    }

    if ("LIMIT".equalsIgnoreCase(orderType)) {
        if (tradableNow) {
            return "DAY_CLOSE";
        } else {
            return "NEXT_TRADING_DAY_CLOSE";
        }
    }

    return "UNKNOWN";
}
```

```java
@Scheduled(cron = "0 0 16 * * MON-FRI", zone = "Asia/Hong_Kong")
public void closeExpiredLimitOrders() {
    LocalDateTime now = LocalDateTime.now(HK_ZONE);

    // 查询所有未完成的限价单
    List<Order> pendingOrders = orderMapper.findPendingLimitOrders();

    for (Order order : pendingOrders) {

            orderMapper.updateById(order);

        }
    }
}
```

```java
public String determineLanguage(String headerLang, String queryLang, String acceptLang) {
    // 1. URL参数 lang (最高优先级)
    if (queryLang != null && !queryLang.isEmpty()) {
```
