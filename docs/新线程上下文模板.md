# 新线程上下文模板（高自治、低跑偏）

> 用法：开新线程时，把下面模板贴进去，按本轮任务替换尖括号内容即可。

## 模板

```md
本轮目标：
<一句话写清这轮要交付什么>

项目入口：
- 先读 /Users/liuliu/Desktop/trading_game/AGENTS.md

本轮范围：
- 允许改动：<目录或模块>
- 禁止改动：<目录或模块>

执行方式：
- 不要先给方案，直接开始实现。
- 除非出现“产品目标冲突 / 破坏性接口变更 / 超出本轮范围”，否则不要停下来问我。
- 你可以做合理假设，但必须在最终说明里写清楚。

必跑验证：
- <命令1>
- <命令2>
- <命令3>

输出要求：
- 说明做了什么
- 说明验证结果
- 说明剩余风险
```

## 交易项目实用版（可直接贴）

```md
本轮目标：
完成 <具体功能>，并保证登录、交易、记录主流程不回归。

项目入口：
- 先读 /Users/liuliu/Desktop/trading_game/AGENTS.md

本轮范围：
- 允许改动：frontend/
- 禁止改动：backend/（除非我明确授权）

执行方式：
- 不要先给方案，直接实现。
- 除非出现“产品目标冲突 / 破坏性接口变更 / 超出 frontend 范围”，否则不要停下来问我。
- 你可以做合理假设，但必须在最终说明里写清楚。

必跑验证：
- cd frontend && npm run test
- cd frontend && npm run test:e2e
- cd frontend && npm run lint
- cd frontend && npm run build

输出要求：
- 说明改了什么
- 说明四条验证命令结果
- 说明剩余风险和后续建议
```

## 什么时候需要补充一句话

- 涉及接口字段或状态枚举：补一句“接口契约不允许破坏性变更”。
- 涉及 UI 对稿：补一句“以 UI设计稿 为高优先级参考”。
- 涉及并行子线程：补一句“前端/后端可并行，但由主线程统一收敛接口字段和状态口径”。
