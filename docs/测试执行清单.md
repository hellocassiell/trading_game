## 5) 交易全流程测试矩阵（核心）

> 每个步骤至少记录：输入、预期、实际、证据链接、结论。

| 步骤 | 用例编号 | 输入 | 预期结果 | 实际结果 | 证据链接（日志/截图/trace） | 结论（通过/失败） |
|---|---|---|---|---|---|---|
| 登录 | T-LOGIN-01 | 手机号+验证码 | 登录成功并返回 userId/token |  |  |  |
| 行情查询 | T-QUOTE-01 | `GET /api/v1/trade/quote/{stockCode}` | 返回最新报价与语言字段 |  |  |  |
| 下单预览 | T-PREVIEW-01 | `POST /api/v1/trade/orders/preview` | 返回费用明细与校验结果 |  |  |  |
| 下单（限价） | T-ORDER-LIMIT-01 | 合法限价单 | 订单进入排队或即时成交 |  |  |  |
| 下单（市价） | T-ORDER-MARKET-01 | 交易时段内市价单 | 即时成交或合理拒绝 |  |  |  |
| 撮合成交 | T-MATCH-01 | 推进行情（MQ/调试接口） | 状态由 pending -> filled/partial |  |  |  |
| 改单 | T-AMEND-01 | `POST /orders/{id}/amend` | 改单生效并状态正确 |  |  |  |
| 撤单 | T-CANCEL-01 | `POST /orders/{id}/cancel` | 撤单成功并释放冻结资金/数量 |  |  |  |
| 持仓资产 | T-ASSET-01 | `GET /account/profile + positions` | 资产、持仓、订单记录一致 |  |  |  |
| 历史记录 | T-HISTORY-01 | `GET /orders/history` | 可见完整订单生命周期 |  |  |  |

### 风控/边界专项（必测）

| 场景 | 用例编号 | 预期 |
|---|---|---|
| 非手数下单 | T-RISK-LOT-01 | 拒绝并返回可读错误 |
| 超出 ±20 ticks | T-RISK-TICK-01 | 拒绝并返回上下限 |
| 买入价低于底线 | T-RISK-FLOOR-01 | 拒绝（买入 < HK$0.05） |
| 卖出价低于底线 | T-RISK-FLOOR-02 | 拒绝（卖出 < HK$0.01） |
| 每日买入超过20笔 | T-RISK-20BUY-01 | 拒绝 |
| 限价排队超过5笔 | T-RISK-QUEUE-01 | 拒绝 |
| 停牌股票下单 | T-RISK-SUSPEND-01 | 仅允许撤单，不允许新增 |
| 重复提交（防抖/幂等） | T-IDEMP-01 | 不产生重复订单 |
