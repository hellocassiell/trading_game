# 港股模拟交易系统进度巡检（2026-03-30）

## 1. 当前进度总览

### 1.1 前端
- 基线构建：`cd frontend && npm run build` 已通过（Next.js 15 + App Router）。
- 页面状态：首页/个人/记录/交易/更多/登录流程/榜单页可访问。
- 数据层状态：仍以 `frontend/lib/mock-data.ts` + adapter 为主，交易提交/撤单/改单与账户资产已走后端 API。
- 多语状态（已落地）：
  - 支持 `zh-Hant` / `zh-Hans` / `en`，默认 `zh-Hant`。
  - `/more` 页面语言切换已生效。
  - 全局请求已透传 `X-Lang` + `lang`（query），前后端可同语种联动。

### 1.2 后端
- 基线测试：`mvn test`（JDK17）最新复验通过 88 个用例（2026-03-31）。
- 接口状态：`/api/v1/*` 账户、榜单、交易、登录链路可用；保留兼容接口 `/api/orders/place`。
- 交易核心状态：
  - 已覆盖下单校验、改单、撤单、手续费、交易时段、限价区间、20 笔买入上限、5 笔轮候上限。
  - 已有重复提交防护（签名 + 1.5s 窗口去重）。
- 多语状态（已落地）：
  - 控制器统一解析 `X-Lang/lang/Accept-Language`。
  - 交易/账户/首页/榜单返回包含 `lang`。
  - 关键错误消息与校验提示已按语言本地化。

### 1.3 联调
- 当前联调方式：前端本地 `localhost:3000` 对接后端 `localhost:8080`。
- 已确认：语言参数可从前端透传到后端，并反映在接口返回数据/错误信息中。

### 1.4 测试
- 前端：`npm run build` 作为当前稳定验证入口（通过）。
- 后端：`mvn test`（JDK17）作为当前稳定验证入口（通过）。
- 缺口：暂无前端自动化 E2E/单测；联调回归仍以手工冒烟为主。

### 1.5 部署
- 现状：仓库未发现 CI/CD 或云端自动化发布流水线。
- 当前建议：继续按本地脚本验证，待需求确认后再引入流水线（构建、测试、部署分阶段门禁）。
